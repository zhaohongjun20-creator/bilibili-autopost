# bilibili-autopost 设计文档

日期：2026-09-11
状态：已确认（用户口头批准："你试试吧"）

## 目标

每天自动从免费素材库（Pexels）按固定主题收集一个视频，用 AI 生成标题/简介/标签，
自动投稿到 B 站账号（UID 1518025639），全程无人值守，本地 Windows 计划任务驱动。

## 合规边界

- 仅使用 Pexels 等免费商用授权（Pexels License）素材库内容
- 简介中自动注明素材来源与原作者署名
- 不搬运其他平台/他人的受版权保护内容
- 发布频率默认每天 1 条，避免触发平台风控

## 架构

```
Windows 计划任务（每天 10:00）
  └─ python main.py
       ├─ ① fetch     Pexels API 搜索 → 按 pexels_id 去重 → 筛选横屏+时长 60-180s
       ├─ ② download  下载视频到 downloads/（SD/HD 画质即可）
       ├─ ③ metadata  智谱 GLM（默认免费 glm-4-flash）生成 标题≤80字/简介/标签
       ├─ ④ cover     ffmpeg 从视频第 3 秒抽帧 → 16:9 封面 jpg
       ├─ ⑤ publish   bilibili-api-python cookie 登录投稿（--dry-run 时跳过）
       └─ ⑥ record    SQLite 记录状态 + 滚动日志文件
```

## 项目结构

│   └── store.py       # SQLite：videos(pexels_id 唯一, status, bvid...)
├── downloads/ logs/ data/   # 运行时目录（git 忽略）
├── tests/             # pytest：去重逻辑、JSON 解析容错

## 关键决策

- **去重**：SQLite `videos.pexels_id` 唯一约束；投稿前二次检查
- **失败处理**：投稿失败保留文件、状态 failed，`--retry-failed` 重投
- **登录态**：启动时调 nav API 预检 isLogin，失效则记 ERROR 并停止（不盲发）
- **dry-run**：走完①-④，把生成的标题/简介/封面路径打印出来供人工检查
- **文案模型**：config 可换（glm-4-flash 免费 → glm-4.6 更强）

## 风险与对策

| 风险 | 对策 |
|------|------|
| bilibili-api 为社区逆向库，接口可能变更 | 素材/文案模块与投稿模块解耦，失效只影响投稿环节 |
| 纯素材视频可能被平台限流 | 简介自动附来源声明+原作者，合规标注 |
| Cookie 约 1 个月过期 | 预检+日志 ERROR 提示，README 写明 3 分钟更新流程 |
| 新号高频投稿风控 | 默认每天 1 条，配置上限 2 |
